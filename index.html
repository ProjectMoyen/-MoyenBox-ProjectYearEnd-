    Tanya saja, meow. Aku tidak menggigit.
    Apakah data invoice dikirim ke internet?

    Tidak. Semua data tersimpan di folder yang Anda pilih di komputer sendiri. Berkasnya bisa dipakai tanpa internet sama sekali.

    Browser apa yang dibutuhkan?

    Microsoft Edge atau Google Chrome di komputer. Keduanya bisa menyimpan langsung ke folder pilihan Anda.

    Install atau versi .html, pilih yang mana?

    Install paling nyaman: ada ikon di desktop dan terbuka di jendela sendiri. Versi .html cocok untuk komputer yang tidak boleh install apa pun atau untuk dibawa di flashdisk. Keduanya aplikasi yang sama dan bisa memakai folder data yang sama.

    Bagaimana kalau ada versi baru?

    Versi install memperbarui dirinya sendiri saat dibuka sambil terhubung internet, lalu aktif setelah ditutup dan dibuka lagi. Untuk versi .html, unduh lagi dan ganti berkas lamanya. Invoice Anda tetap aman di folder ProjectYearEnd-Data.

    Bagaimana cara menghapusnya?

    Buka aplikasinya, tekan menu ⋮ di pojok kanan atas, lalu pilih Uninstall. Folder data Anda tidak ikut terhapus.

    Bagaimana cara membuat cadangan?

    Salin folder ProjectYearEnd-Data ke flashdisk atau OneDrive. Di aplikasinya juga ada Export untuk menyimpan semuanya sekaligus.

    Siap lebih cepat dari Mas Word?

    Install sekali, invoice pertama Anda selesai dalam hitungan menit.
